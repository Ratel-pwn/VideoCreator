# Metadata Generator

## Goal

Create publishing-ready metadata for the final video project.

## Owns

- title generation
- tag generation
- description generation
- open-source URL first-line rule when applicable
- deliverable path references

## Output

- machine-readable metadata
- human-readable metadata summary
