# Cover Generator

## Goal

Produce consistent cover assets and editable cover sources across required ratios.

## Owns

- cover ratio requirements
- cover output naming
- editable cover source retention

## Default Ratios

- `3:4`
- `9:16`
- `4:3`
- `16:9`
