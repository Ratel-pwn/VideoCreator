# Source Material Verifier

## Goal

Confirm that the input source can be read directly and is suitable for downstream writing and visual work.

## Owns

- verifying accessible source materials
- preferring direct source capture over summaries
- identifying missing or blocked sources

## Input

- source URLs
- source files
- user constraints on what counts as authoritative

## Output

- verified source list
- blocked source list
- recommended primary source set for the next stage

## Does Not Own

- final script writing
- subtitle generation
- visual planning
