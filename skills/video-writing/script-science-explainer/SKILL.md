# Script Science Explainer

## Goal

Write short-form explainer narration that orients the viewer, explains the mechanism, and lands the key takeaway clearly.

## Output Characteristics

- problem or question first
- mechanism-focused structure
- examples used to clarify, not distract
- stronger conceptual continuity than product promo scripts
