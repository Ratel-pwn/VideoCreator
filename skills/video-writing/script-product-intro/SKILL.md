# Script Product Intro

## Goal

Write short-form narration focused on product identity, use case, workflow fit, and proof.

## Output Characteristics

- project-first opening
- clear category and use case
- evidence-aware phrasing
- concise, spoken-language rhythm

## Does Not Own

- TTS
- subtitle timing
- scene layout
